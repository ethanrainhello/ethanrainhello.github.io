mail-sync Privacy Policy

Last updated: 2026-10-17

mail-sync is a personal tool used only by its owner. It is not offered to other users.

Data accessed

The tool reads new messages from the owner's own IMAP mailbox and inserts them into the owner's own Gmail account through the Gmail API using only the gmail.insert scope. It cannot read, modify or delete existing Gmail messages.

Storage and sharing

Messages are passed directly from the IMAP server to Gmail and are not stored elsewhere. The only local data kept is the OAuth token and the last processed message position. No data is sold, shared with third parties, or used for advertising or AI training.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
