hibox-to-gmail

hibox-to-gmail is a private, single-user tool. It runs an instance of the open-source turbogmailify mail forwarder that reads new messages from the owner's own IMAP mailbox and inserts them into the owner's own Gmail inbox using the Gmail API (gmail.insert scope).

It is not offered to the public. Only the owner signs in, and no one else's data is accessed.
